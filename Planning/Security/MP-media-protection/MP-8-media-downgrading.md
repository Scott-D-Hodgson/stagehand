# MP-8 — Media Downgrading

**Source:** [ITSG-33 Annex 3A, MP-8](https://www.cyber.gc.ca/en/guidance/annex-3a-security-control-catalogue-itsg-33#a310mp8).

## Control definition

Sanitize or downgrade media before releasing it to individuals without the required access authorization, using approved procedures.

## Supplemental guidance

Downgrading reduces media’s sensitivity marking only after authorized review and sanitization. It requires defined procedures and authorized personnel; ordinary file deletion or removing a label is insufficient.

## Plain-language metaphor

Before a restricted package is relabeled for general delivery, an authorized checker must remove or sanitize the restricted contents.

## Stagehand and operator guidance

Do not use Stagehand to downgrade or release classified/sensitive artifacts without a separately approved process and human authority. Operators should review the complete artifact, metadata, embedded images, traces, and copies, apply approved sanitization, and document authorization before changing markings.
