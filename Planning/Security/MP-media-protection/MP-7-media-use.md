# MP-7 — Media Use

**Source:** [ITSG-33 Annex 3A, MP-7](https://www.cyber.gc.ca/en/guidance/annex-3a-security-control-catalogue-itsg-33).

## Control definition

Restrict or prohibit defined types of digital and non-digital media on defined systems or system components using organisation-defined controls.

**Organisation-defined parameters:** media types, systems/components, and controls.

## Supplemental guidance

Portable media can introduce malicious code or remove sensitive information. Organisations may restrict media by type, authorization, device, or operational environment.

## Plain-language metaphor

Do not plug an unknown key into the workshop computer; only approved tools may connect.

## Stagehand and operator guidance

Restrict USB and removable storage on automation hosts according to policy. Define whether plans and artifacts may be imported/exported on removable media, and scan/authorize media before use. Use approved repositories and avoid transferring sensitive browser artifacts to unmanaged devices.
