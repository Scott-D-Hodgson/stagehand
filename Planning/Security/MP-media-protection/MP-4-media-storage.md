# MP-4 — Media Storage

**Source:** [ITSG-33 Annex 3A, MP-4](https://www.cyber.gc.ca/en/guidance/annex-3a-security-control-catalogue-itsg-33).

## Control definition

Physically control and securely store digital and non-digital media containing organisational information within defined controlled areas.

**Organisation-defined parameter:** controlled storage areas and access conditions.

## Supplemental guidance

Storage controls apply to media whether online or offline, and should match sensitivity and physical-security requirements. Protect media against unauthorized access, environmental damage, and loss.

## Plain-language metaphor

Store important records in a locked, suitable room, not on an unattended desk or in an open hallway.

## Stagehand and operator guidance

Define storage locations and access for project plans, browser profiles, logs, and output artifacts. For hosted deployments, review provider storage regions, encryption, administrator access, backups, and deletion behaviour. Avoid persisting browser data when the workflow does not need it.
