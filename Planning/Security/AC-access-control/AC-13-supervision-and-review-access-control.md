# AC-13 — Supervision and Review — Access Control

**Status:** Withdrawn in ITSG-33 Annex 3A. **Source:** [ITSG-33 Annex 3A](https://www.cyber.gc.ca/en/guidance/annex-3a-security-control-catalogue-itsg-33).

## Control definition and guidance

The catalogue marks AC-13 as withdrawn and incorporated into AC-2 (Account Management) and AU-6 (Audit Review, Analysis, and Reporting). It has no separate active control statement or enhancement to implement in this catalogue.

## Plain-language explanation

This old checklist item was folded into the account-management and audit-review checklists, so follow those current entries instead of maintaining a duplicate rule.

## Stagehand mapping and operator guidance

Use AC-2 for account review and AU-6 for review of audit records in the repository, CI, identity provider, target services, and artifact platform. Stagehand's functional test reports are not a substitute for security audit review. Do not mark AC-13 satisfied independently.

## Enhancements

None listed for the withdrawn entry. Preserve the identifier for traceability only; follow the catalogue's incorporation note.

## Supplemental Guidance summary

Annex 3A marks this control withdrawn and incorporated into successor controls; it provides no separate active Supplemental Guidance for this identifier.

## Parameters - suggestions for review

No separate organisation-defined parameters apply to this withdrawn entry.
