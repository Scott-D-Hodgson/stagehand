# Access Control

> **Living document:** All material in `Planning/` is generated by AI through discussions and direction from the developer; it is not written by hand. It provides structure, guidance, and context for ongoing development, and will be reviewed and updated periodically as Stagehand evolves.

See [Security control documentation guidance](../README.md) for the required record format and status rules. Add one Markdown file per official control identifier in this family, with its enhancements documented in that control's file. Source: [ITSG-33 Annex 3A](https://www.cyber.gc.ca/en/guidance/annex-3a-security-control-catalogue-itsg-33).

> Preliminary control records are not implementation evidence and do not mark controls satisfied.
