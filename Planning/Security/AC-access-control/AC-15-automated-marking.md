# AC-15 — Automated Marking

**Status:** Withdrawn in ITSG-33 Annex 3A. **Source:** [ITSG-33 Annex 3A](https://www.cyber.gc.ca/en/guidance/annex-3a-security-control-catalogue-itsg-33).

## Control definition and guidance

The catalogue marks AC-15 as withdrawn and incorporated into MP-3 (Media Marking). There is no separate active control statement or enhancement in this entry.

## Plain-language explanation

The old label-maker rule moved to the media-protection section, where handling and marking of information are addressed together.

## Stagehand mapping and operator guidance

Assess applicable marking requirements under MP-3 for plans, reports, screenshots, traces, and removable media. Stagehand should document artifact contents and support safe handling, but no automatic classification marking is currently implemented or promised.

## Enhancements

None listed for the withdrawn entry. Track any applicable requirement under MP-3 and the currently required catalogue/profile.

## Supplemental Guidance summary

Annex 3A marks this control withdrawn and incorporated into successor controls; it provides no separate active Supplemental Guidance for this identifier.

## Parameters - suggestions for review

No separate organisation-defined parameters apply to this withdrawn entry.
