# SC-38 - Operations Security

**Source:** [ITSG-33 Annex 3A, SC-38](https://www.cyber.gc.ca/en/guidance/annex-3a-security-control-catalogue-itsg-33).

## Control definition

Use defined operations-security safeguards to protect key organisational information throughout the system lifecycle.

**Organisation-defined parameter:** OPSEC safeguards. **Suggestion for review:** identify sensitive operational details, threats, vulnerabilities, and appropriate sharing/handling safeguards with the organisation’s security authority.

## Supplemental guidance

OPSEC systematically identifies critical information, analyses threats and vulnerabilities, assesses risks, and applies countermeasures. It includes protecting details such as users, suppliers, designs, tests, and security implementations, including within the operating environment.

## Plain-language metaphor

Like not posting a facility’s schedule, guard routes, and weak doors where an intruder can piece them together.

## Stagehand and operator guidance

Maintainers should avoid exposing secrets or sensitive deployment details in public artifacts. Operators should control sharing of plans, screenshots, traces, and reports, and disclose only necessary information to suppliers and external parties.
