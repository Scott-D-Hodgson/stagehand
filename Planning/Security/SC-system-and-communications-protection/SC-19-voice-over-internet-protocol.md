# SC-19 - Voice over Internet Protocol

**Source:** [ITSG-33 Annex 3A, SC-19](https://www.cyber.gc.ca/en/guidance/annex-3a-security-control-catalogue-itsg-33#a316sc19).

## Control definition

Set use restrictions and implementation guidance for VoIP based on potential harm, and authorize, monitor, and control its use.

## Supplemental guidance

The catalogue relates this control to configuration management, boundary protection, and collaborative devices. Its enhancement guidance references classified-facility restrictions.

## Plain-language metaphor

Like setting rules for which phone lines may connect to secure rooms.

## Stagehand and operator guidance

VoIP is outside Stagehand’s application function. Operators in classified facilities should follow the applicable facility and telecommunications rules; no Stagehand configuration can establish this control.

## Control enhancements

(1) unclassified VoIP is prohibited in classified facilities unless converted to POTS before leaving the facility boundary; (2) unclassified VoIP over a LAN with access to a public data network is prohibited in classified facilities. These apply only in the stated classified-facility context.

## Assessment status

**Planned / not applicable to application function; facility-dependent.**
