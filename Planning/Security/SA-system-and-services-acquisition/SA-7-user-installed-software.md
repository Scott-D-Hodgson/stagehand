# SA-7 - User-Installed Software

**Source:** [ITSG-33 Annex 3A, SA-7](https://www.cyber.gc.ca/en/guidance/annex-3a-security-control-catalogue-itsg-33).

## Control definition

Withdrawn control. Annex 3A incorporates SA-7 into CM-11 (User-Installed Software) and SI-7 (Software, Firmware, and Information Integrity).

## Supplemental guidance

The source marks the control withdrawn; consult CM-11 and SI-7 for active requirements.

## Plain-language metaphor

The rule moved into the current checklist for software users can install and the check that verifies software has not been altered.

## Stagehand and operator guidance

Operators should control user-installed software through CM-11 and verify integrity under SI-7. Restrict installation of browser extensions, runner dependencies, and other software according to local policy.

## Control enhancements

No separate active enhancements; withdrawn and incorporated into CM-11 and SI-7.

## Assessment status

**Withdrawn / tracked through successor controls.**
