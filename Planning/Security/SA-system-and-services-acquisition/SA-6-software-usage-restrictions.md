# SA-6 - Software Usage Restrictions

**Source:** [ITSG-33 Annex 3A, SA-6](https://www.cyber.gc.ca/en/guidance/annex-3a-security-control-catalogue-itsg-33).

## Control definition

Withdrawn control. Annex 3A incorporates SA-6 into CM-10 (Software Usage Restrictions) and SI-7 (Software, Firmware, and Information Integrity).

## Supplemental guidance

The source marks the control withdrawn; consult CM-10 and SI-7 for the active requirements.

## Plain-language metaphor

The rule moved into the current software-use and integrity checklists, like merging an old procedure into the manuals that now govern it.

## Stagehand and operator guidance

Assess software licensing and permitted use under CM-10, and software integrity under SI-7. No separate SA-6 implementation should be claimed.

## Control enhancements

No separate active enhancements; withdrawn and incorporated into CM-10 and SI-7.

## Assessment status

**Withdrawn / tracked through successor controls.**
