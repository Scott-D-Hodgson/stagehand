# PS-7 — Third-Party Personnel Security

**Source:** [ITSG-33 Annex 3A, PS-7](https://www.cyber.gc.ca/en/guidance/annex-3a-security-control-catalogue-itsg-33).

## Control definition

Set and document personnel-security duties for providers; require compliance, timely notice of provider staff changes, monitor compliance, apply required screening for protected/classified access, and define government oversight and user roles.

Suggested review: require notice before or within one business day of a privileged provider staff change; define accountable contract and security roles.

## Supplemental guidance

Providers can include contractors, development, hosting, IT, network, and security services. Contract documents should carry the requirements.

## Plain-language metaphor

Like ensuring a locksmith hired by the building follows the same key-control rules.

## Stagehand and operator guidance

Stagehand’s hosting and CI are deployment choices. Operators should contractually assess providers, staffing controls, incident notification, and access termination; maintainers should apply equivalent controls to any future service provider.

## Control enhancements

None listed.

## Assessment status

**Planned / not verified.** Stagehand implementation and deployment evidence must be assessed before assigning an implemented or compliant status. This summary is a paraphrase for planning, not an authorization decision.
