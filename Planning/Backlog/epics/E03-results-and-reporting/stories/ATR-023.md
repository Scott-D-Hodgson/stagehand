# ATR-023 — Generate HTML reports

**Epic:** E03  
**Status:** Proposed  
**Priority:** Later  
**Release:** Later

## User story

As a test operator, I want an HTML report so that I can inspect run outcomes and diagnostics without specialized tooling.

## Description

Generate a human-readable report from the common result model.

## Acceptance criteria

### AC-1 — Summary view

Report shows overall status, counts, and durations.

### AC-2 — Test details

Report shows each test and its step outcomes.

### AC-3 — Distinct findings

Hard failures, soft assertion failures, accessibility findings, and runner errors are visually distinguishable.

### AC-4 — Localization

Localized test and step descriptions are shown as resolved for the run.

### AC-5 — Safe output

Secret values are not disclosed.

### AC-6 — Portable report

Report can be opened locally without requiring a report server.
