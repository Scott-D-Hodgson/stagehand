# ATR-024 — Capture diagnostic artifacts

**Epic:** E03  
**Status:** Proposed  
**Priority:** Later  
**Release:** Later

## User story

As a test operator, I want optional diagnostic artifacts so that I can investigate failures more efficiently.

## Description

In later work, allow screenshot capture to be opted into through plan or CLI configuration and associate artifact paths with case/step results. Screenshot capture is not in the MVP.

## Acceptance criteria

### AC-1 — Screenshot policy

Screenshot capture is off unless enabled through plan or CLI configuration. The supported failure/error triggers are documented.

### AC-2 — Failure association

Captured artifacts are associated with the relevant test and step.

### AC-3 — Artifact errors

Artifact capture errors are recorded without obscuring the original failure.

### AC-4 — Sensitive data

Documentation warns about sensitive content in screenshots and supports safe artifact handling.
