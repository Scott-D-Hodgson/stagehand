# ATR-021 — Generate JSON reports

**Epic:** E03  
**Status:** Proposed  
**Priority:** Must  
**Release:** MVP

## User story

As a test operator, I want JSON output so that other tools can aggregate or process current-run results.

## Description

Generate JSON using the versioned result contract.

## Acceptance criteria

### AC-1 — Valid JSON

The report is valid JSON and conforms to the documented result schema.

### AC-2 — Current run

The report represents the current run without requiring a history database.

### AC-3 — Diagnostics included

Case and step outcomes and relevant diagnostics are present. Step identity uses the case ID and zero-based index defined by [ATR-020](ATR-020.md).

### AC-4 — Output errors

Write failures are surfaced and do not produce a false success result.

## Dependencies

- ATR-020
- ATR-004

- Add unit, integration, or manual verification appropriate to the acceptance criteria.
