# ATR-041 — Provide a future wiki migration/export tool

**Epic:** E09  
**Status:** Proposed  
**Priority:** Later  
**Release:** Future

## User story

As a documentation maintainer, I want to export the canonical Markdown documentation to another wiki format so that organisations can reuse the content.

## Description

Investigate and implement export adapters only when a target platform is selected.

## Acceptance criteria

### AC-1 — Target format defined

At least one supported target wiki platform or interchange format is documented.

### AC-2 — Content preserved

Headings, links, images, and navigation metadata are converted according to documented rules.

### AC-3 — Dry run

The tool can preview or report changes before writing output.

### AC-4 — Source preserved

Export does not modify canonical documentation.
