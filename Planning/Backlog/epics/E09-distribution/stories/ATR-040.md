# ATR-040 — Package the editor for offline desktop use

**Epic:** E09  
**Status:** Proposed  
**Priority:** Later  
**Release:** Later

## User story

As a test author, I want an optional desktop application so that I can edit plans offline or in a controlled environment.

## Description

Package the same Vue SPA using Electron without forking editor behaviour.

## Acceptance criteria

### AC-1 — Shared editor

Desktop app uses the same core editor code as the web SPA.

### AC-2 — Local files

Desktop app can open and save user-selected JSON files.

### AC-3 — Offline editing

Editing and schema validation work without network access when required assets are available.

### AC-4 — Security

Electron security settings follow least privilege and avoid unsafe renderer privileges.

### AC-5 — Distribution

Build and installation instructions are documented.
