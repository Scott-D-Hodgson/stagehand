# ATR-032 — Integrate runner execution into CI/CD pipelines

**Epic:** E06  
**Status:** Proposed  
**Priority:** Must  
**Release:** MVP

## User story

As a CI/CD maintainer, I want to invoke the runner in a pipeline so that end-to-end checks can gate or inform delivery.

## Description

Provide pipeline examples using the CLI and report artifacts.

## Acceptance criteria

### AC-1 — CLI invocation

A pipeline can pass a plan and CLI overrides.

### AC-2 — Exit status

Pipeline outcome reflects the CLI exit code.

### AC-3 — JSON artifact

An example retains the Stagehand JSON result as a pipeline artifact.

### AC-4 — Artifact collection

The JSON result can be retained by the pipeline. HTML and diagnostic artifacts are deferred.

### AC-5 — Secrets

Pipeline secrets are passed through environment variables or an approved secret mechanism.
