# ATR-033 — Integrate with .NET xUnit

**Epic:** E06  
**Status:** Proposed  
**Priority:** Later
**Release:** Later

## User story

As a .NET test developer, I want to invoke the runner from xUnit so that browser test outcomes can participate in an existing .NET test suite.

## Description

Initially use the Node.js CLI as a child process rather than pretending the Node library is a directly referenceable .NET assembly.

## Acceptance criteria

### AC-1 — Invoke CLI

An xUnit test can launch the runner CLI with a JSON plan.

### AC-2 — Await completion

The wrapper awaits process completion and captures exit code/output.

### AC-3 — Map outcomes

Runner success maps to a passing xUnit test and test/runner failures map to a failing xUnit test.

### AC-4 — Diagnostics

Useful runner output is attached to or surfaced by the xUnit failure.

### AC-5 — Prerequisites

Node.js, runner package, browser availability, and paths are documented.
