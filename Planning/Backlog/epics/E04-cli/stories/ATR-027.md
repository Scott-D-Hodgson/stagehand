# ATR-027 — Return reliable CLI exit codes

**Epic:** E04  
**Status:** Proposed  
**Priority:** Must  
**Release:** MVP

## User story

As a CI/CD maintainer, I want reliable exit codes so that pipelines can determine whether a run succeeded.

## Description

Document and implement exit codes for successful runs, test failures, validation failures, and runner errors.

## Acceptance criteria

### AC-1 — Success

A successful run returns exit code zero.

### AC-2 — Test failure

A run with required test failures returns a documented nonzero code.

### AC-3 — Invalid plan/arguments

Validation or argument errors return a documented nonzero code.

### AC-4 — Runner failure

Runner-level failures return a documented nonzero code.

### AC-5 — Consistency

Exit code behaviour is covered by automated CLI tests.
