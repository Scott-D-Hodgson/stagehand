# ATR-028 — Support external scheduled execution

**Epic:** E04  
**Status:** Proposed  
**Priority:** Must  
**Release:** MVP

## User story

As an operator, I want the CLI to run under Task Scheduler or cron so that plans can execute on a schedule without a built-in scheduler.

## Description

Provide noninteractive behaviour and documented invocation examples.

## Acceptance criteria

### AC-1 — No interactive dependency

Scheduled execution requires no interactive prompts.

### AC-2 — Stable outputs

Output paths and exit codes are suitable for scheduled collection.

### AC-3 — Documentation

Task Scheduler and cron examples are provided.

### AC-4 — Configuration

Environment variables and configuration overrides are documented for scheduled runs.
