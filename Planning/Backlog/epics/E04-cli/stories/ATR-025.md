# ATR-025 — Execute a plan from the CLI

**Epic:** E04  
**Status:** Proposed  
**Priority:** Must  
**Release:** MVP

## User story

As a developer or operator, I want to execute a JSON plan from the command line so that tests can be run manually or automatically.

## Description

Provide plan path and execution options while keeping the CLI thin.

## Acceptance criteria

### AC-1 — Plan input

CLI accepts a plan file path.

### AC-2 — Library delegation

CLI delegates execution to the reusable library.

### AC-3 — Noninteractive

CLI can run without prompts.

### AC-4 — Validation errors

Invalid arguments and plans produce actionable errors.

### AC-5 — General execution warning
Before starting a plan, the CLI displays a non-blocking general warning that operators must verify target authorization and consider possible side effects, network egress/downloads, limits, and costs. The warning does not claim to identify production targets and does not require acknowledgement.

### AC-6 — Production-specific handling deferred
MVP does not claim automatic production-target identification or require a production-specific acknowledgement gate. Revisit those capabilities under [TE-019](../../../technical-enablers/te-019-production-target-identification-and-warning.md) after target-environment classification is defined.
