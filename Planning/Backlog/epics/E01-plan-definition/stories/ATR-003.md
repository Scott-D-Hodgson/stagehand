# ATR-003 — Configure browser and viewport

**Epic:** E01  
**Status:** Proposed  
**Priority:** Must  
**Release:** MVP

## User story

As a test author, I want browser settings in the plan so that I can test the application under specified browser conditions.

## Description

Support the initial Windows/Playwright-managed Chromium baseline, headed/headless mode, timezone, locale, and viewport dimensions. Linux and Edge are a later support expansion after the baseline is proven.

## Acceptance criteria

### AC-1 — Browser type

The plan can select the supported initial browser using a documented identifier. The initial proposal is Playwright-managed Chromium on Windows; branded Google Chrome, Linux, and Edge support must be explicitly distinguished and staged in the support matrix.

### AC-2 — Headless mode

The plan can enable or disable headless execution.

### AC-3 — Timezone

The browser context uses a valid IANA timezone identifier.

### AC-4 — Locale

The plan run has a default browser locale/culture code such as en-CA or fr-CA. Each case inherits that locale unless its case configuration explicitly overrides it.

### AC-5 — Viewport

Viewport width and height are applied in CSS pixels.

### AC-6 — Invalid configuration

Unsupported browsers, invalid timezones/locales where detectable, and invalid viewport dimensions are rejected with actionable errors.

## Dependencies

## Verification

## Notes

- The initial target is Windows with Playwright-managed Chromium. Branded Google Chrome is not a separate initial requirement; Linux and Edge are post-MVP expansions.
