# ATR-003 — Configure browser and viewport

**Epic:** E01  
**Status:** Proposed  
**Priority:** Must  
**Release:** MVP

## User story

As a test author, I want browser settings in the plan so that I can test the application under specified browser conditions.

## Description

Support the MVP Windows/Playwright-managed Chromium baseline, headed/headless mode, timezone, locale, and viewport dimensions. Linux runner and Edge support are post-MVP expansions. During development, prefer designs that work on both Windows and Linux when practical.

## Acceptance criteria

### AC-1 — Browser type

The plan can select the supported initial browser using the identifier `chromium`, representing Playwright-managed Chromium on Windows. Branded Google Chrome, Linux, and Edge support must be explicitly distinguished and staged in the support matrix. If omitted, the browser type defaults to `chromium`.

### AC-2 — Headless mode

The plan can enable or disable headless execution. If omitted, headless mode defaults to `true`. A case can override the plan's setting.

### AC-3 — Timezone

The browser context uses a valid IANA time zone identifier. If omitted, it defaults to `UTC`. A case can override the plan's setting.

### AC-4 — Locale

The plan has one run-wide browser locale using a BCP 47 tag such as `en-CA` or `fr-CA`. If omitted, it defaults to `en-CA`. Cases inherit the locale and cannot override it; testing another locale requires a separate run.

### AC-5 — Viewport

Viewport width and height are positive integer CSS pixel values. If omitted, they default to 1280 by 720. No Stagehand-specific upper bound is imposed; browser or platform limitations produce an actionable error.

### AC-6 — Invalid configuration

Unsupported browsers, invalid IANA time zones or BCP 47 locales where detectable, and invalid viewport dimensions are rejected with actionable errors.
