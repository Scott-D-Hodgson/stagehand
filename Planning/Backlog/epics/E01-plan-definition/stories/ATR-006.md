# ATR-006 — Select cases from a plan

**Epic:** E01  
**Status:** Proposed  
**Priority:** Should  
**Release:** Later

## User story

As a test operator, I want to select cases by stable ID so that I can run a subset of a plan without maintaining duplicate files.

## Description

Support full-plan execution and selecting one or more case IDs.

## Acceptance criteria

### AC-1 — Full plan

Without a selection filter, all eligible cases are considered.

### AC-2 — Select by ID

CLI/API can select cases by stable IDs.

### AC-3 — Unknown IDs

Unknown case IDs produce a clear validation or selection error.

### AC-4 — Result scope

The result identifies which cases were selected and executed.
