# Epics

> **Living document:** All material in `Planning/` is generated by AI through discussions and direction from the developer; it is not written by hand. It provides structure, guidance, and context for ongoing development, and will be reviewed and updated periodically as Stagehand evolves.

Epics group related user stories. Each epic has a short overview and a `stories/` directory containing one Markdown file per story.

| Epic | Name | Focus |
|---|---|---|
| E01 | Plan definition and configuration | Versioned JSON contract, validation, browser and run configuration |
| E02 | Execution engine | Reusable library, Playwright actions, shared steps, variables, failure handling; loops deferred |
| E03 | Results and reporting | Result contract, JSON output, diagnostics, accessibility findings; XML/HTML conversions and screenshots are later work |
| E04 | CLI and scheduling | CLI options, overrides, exit codes, non-interactive scheduled runs |
| E05 | Local-first web editor | Vue SPA for user-owned test plan files |
| E06 | CI/CD and external integrations | Azure DevOps pipeline publishing; .NET xUnit is later work |
| E07 | Documentation and adoption | Markdown docs and Hugo website |
| E08 | Developer experience and contribution | Monorepo, dev container, agent guidance, CI checks |
| E09 | Distribution and future extensions | Desktop packaging and future optional services |
