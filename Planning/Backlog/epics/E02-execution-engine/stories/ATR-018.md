# ATR-018 — Support controlled loops over variable lists

**Epic:** E02  
**Status:** Proposed  
**Priority:** Must  
**Release:** MVP

## User story

As a test author, I want to loop through a list of values and execute a set of steps for each item so that data-driven scenarios can be expressed without duplicating steps.

## Description

Support bounded iteration over a list-valued variable with an iteration-scoped value.

## Acceptance criteria

### AC-1 — List source

A loop can reference a list-valued variable.

### AC-2 — Iteration value

Each iteration exposes the current item and index to the loop body.

### AC-3 — Ordered iterations

Iterations execute in a deterministic order.

### AC-4 — Failure policy

Hard/soft assertion and action-failure rules apply within each iteration according to documented loop policy.

### AC-5 — Bounded execution

Maximum iterations defaults to 10. Plan and case configuration may override that limit. Loop execution also observes the applicable plan/case timeout, preventing unbounded runs.

### AC-6 — Diagnostics

Results identify the iteration associated with each step outcome.

### AC-7 — Scope

Loop variables are scoped so they do not unintentionally overwrite unrelated test variables.

## Dependencies

- ATR-012

## Verification

- Add unit, integration, or manual verification appropriate to the acceptance criteria.

## Notes

- A hard assertion failure inside a loop stops the current case immediately, exiting the loop and any remaining steps in that case.
