# ATR-017 — Resolve protected values from environment variables

**Epic:** E02  
**Status:** Proposed  
**Priority:** Must  
**Release:** MVP

## User story

As a test author, I want plans to reference protected values by environment-variable name so that secrets do not need to be stored in JSON.

## Description

Support external secret/value references, redaction, and validation before use.

## Acceptance criteria

### AC-1 — Reference only

The plan stores the environment-variable name, not the protected value.

### AC-2 — Runtime resolution

The runner resolves the reference from the process environment before browser startup. Environment variables are the only supported secret source in the initial release.

### AC-3 — Missing secret

A missing required environment variable fails validation before any browser is started and reports the variable name without disclosing a value.

### AC-4 — Redaction

Resolved protected values are redacted from logs, errors, and reports.

### AC-5 — No accidental export

The effective configuration and exported plan do not contain resolved secret values.
