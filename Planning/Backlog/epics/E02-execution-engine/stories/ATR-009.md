# ATR-009 — Execute steps in order within each test

**Epic:** E02  
**Status:** Proposed  
**Priority:** Must  
**Release:** MVP

## User story

As a test author, I want steps within a test to execute in a defined order so that a test's behaviour is deterministic and understandable.

## Description

Run each test's steps sequentially in declared order for the initial release.

## Acceptance criteria

### AC-1 — Order preserved

Steps execute in the order defined by the plan.

### AC-2 — Await completion

The runner awaits each asynchronous action before starting the next step.

### AC-3 — Traceable execution

Results preserve step identity and execution order.
