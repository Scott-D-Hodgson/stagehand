# ATR-008 — Execute supported Playwright browser actions

**Epic:** E02  
**Status:** Proposed  
**Priority:** Must  
**Release:** MVP

## User story

As a test author, I want declarative browser actions so that I can describe end-to-end flows without writing a separate test program for each flow.

## Description

Implement the initial documented action and assertion vocabulary for browser-based tests. Prefer user-facing role and label locators; also allow CSS selector and XPath escape hatches. The initial MVP scope is intended to be authorable by a non-technical tester in the Phase 2 Vue editor.

## Acceptance criteria

### AC-1 — Locator choices

The author can identify elements with preferred user-facing role or label locators, with CSS selector and XPath escape hatches for cases those locators cannot express. Locator strategy is documented and validated by the shared plan schema.

### AC-2 — Navigation

Support navigating to a URL. Navigation supports an optional bounded wait for a documented post-navigation state, initially including DOM ready and network idle. Reload, back, and forward are deferred to [ATR-042](ATR-042.md).

### AC-3 — Interaction

Support selecting a page item by selector, clicking an item, typing characters into a field, setting a field value directly (Playwright `fill`-style), and selecting an option in a page dropdown.

The click item in the request is treated as the same click operation listed here, not a second distinct action. Add distinct click variants (such as double-click) only if separately specified.

Supported interactions may specify optional pre-action and post-action behaviour:

- Wait, with a bounded timeout, for a selector to exist.
- Delay for a specified duration.
- Wait for a documented navigation state, including DOM ready or network idle where applicable.
- Bring the target item into the viewport when it is offscreen.

Define which pre/post options apply to each action, their ordering, and timeout/error behaviour. Do not assume arbitrary delays or waits are always appropriate; document them as explicit, bounded options.

### AC-4 — Waiting

Support bounded waits for selectors and documented page states needed by navigation and interaction options. Standalone URL waits are deferred with the extended action vocabulary in [ATR-042](ATR-042.md).

### AC-5 — Assertions

Support markup assertions that locate an item and compare its inner text or inner HTML with an expected value. Support input assertions that locate an input and compare its current value with an expected value. Input assertions may also include an optional soft assertion for the associated label's inner text or inner HTML. Define label association resolution and behaviour when no associated label exists. Other assertion types, including visibility, enabled/disabled, checked state, attributes, URL, and page title, are deferred to [ATR-042](ATR-042.md).

### AC-6 — Step results

Each action produces a structured step outcome and duration.

### AC-7 — Diagnostics

Playwright errors are translated into useful diagnostics without losing relevant technical detail.
