# ATR-012 — Capture step-level diagnostics

**Epic:** E02  
**Status:** Proposed  
**Priority:** Must  
**Release:** MVP

## User story

As a test operator, I want detailed step diagnostics so that I can understand where and why a test failed.

## Description

Track the test execution, current step, iteration context, error category, and relevant diagnostic data.

## Acceptance criteria

### AC-1 — Identity

Each step result identifies the case ID and the step's zero-based index in its case sequence. Authors do not assign step IDs.

### AC-2 — Error category

Diagnostics distinguish assertion failure, action/execution error, timeout, validation error, and runner-level error where applicable.

### AC-3 — Loop context

Looped steps include iteration index and safe, non-secret context.

### AC-4 — Secret redaction

Resolved secret values are not written to logs or reports.

### AC-5 — Current location

The execution context tracks the current test and step during execution.
