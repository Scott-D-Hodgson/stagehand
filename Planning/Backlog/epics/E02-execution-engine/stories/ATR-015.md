# ATR-015 — Support shared reusable step groups

**Epic:** E02  
**Status:** Proposed  
**Priority:** Must  
**Release:** MVP

## User story

As a test author, I want to define shared step groups and reference them from multiple tests so that common flows are maintained in one place.

## Description

Support named reusable step groups with stable IDs, validation, and traceable execution. A shared step uses the calling case's variables and has no separate parameter or variable-default mechanism.

## Acceptance criteria

### AC-1 — Define shared group

A plan can define a shared step group with a stable identifier.

### AC-2 — Reference group

A case can invoke a shared group by identifier.

### AC-3 — Case variable context

A shared step resolves variables from the calling case, including values imported from its selected named data set. Variables needed by the shared step must be defined in that case context.

### AC-4 — Unknown reference

An unknown shared-group ID is rejected during plan validation.

### AC-5 — Traceability

Results identify both the calling test step and the shared step being executed.

### AC-6 — Recursion policy

Shared-step groups cannot reference another shared-step group. Such references are rejected during validation.

## Dependencies

- ATR-009

## Verification

- Add unit, integration, or manual verification appropriate to the acceptance criteria.

## Notes

- Shared-step groups are exactly one level deep; a reference to another group from within a shared group is invalid.
