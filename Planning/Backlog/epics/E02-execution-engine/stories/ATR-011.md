# ATR-011 — Produce a current-run summary

**Epic:** E02  
**Status:** Proposed  
**Priority:** Must  
**Release:** MVP

## User story

As a test operator, I want a summary of the current run so that I can quickly understand the outcome.

## Description

Provide totals, outcomes, durations, and overall status without requiring long-term run storage.

## Acceptance criteria

### AC-1 — Counts

Summary includes total cases and counts by each outcome defined in ATR-020. Do not report skipped cases in the MVP unless a feature that deliberately omits cases is added.

### AC-2 — Duration

Run and case durations are included.

### AC-3 — Overall status

Overall status reflects case failures, cancellation, and runner-level errors according to documented policy.

### AC-4 — No historical database required

The run can be summarized and exported without storing history in a product database.

## Dependencies

- ATR-007
- ATR-010

## Verification

- Add unit, integration, or manual verification appropriate to the acceptance criteria.
