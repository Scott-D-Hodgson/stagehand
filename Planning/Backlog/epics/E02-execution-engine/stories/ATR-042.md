# ATR-042 — Extend browser navigation and assertion vocabulary

**Epic:** E02  
**Status:** Proposed  
**Priority:** Later  
**Release:** Later

## User story

As a test author, I want additional browser navigation and assertion actions so that I can describe flows beyond the initial MVP vocabulary.

## Description

Evaluate and, if useful, add browser reload/back/forward actions, standalone URL waits, distinct click variants, and additional assertions. This story is explicitly outside the MVP; the MVP action and assertion set remains defined by ATR-008.

## Candidate capabilities

- Reload the current page and navigate backward or forward through browser history.
- Wait for a URL or URL pattern independently of a navigation action.
- Add distinct click variants such as double-click.
- Add visibility, enabled/disabled, checked-state, attribute, URL, or page-title assertions.
- Add substring (`contains`) text comparisons if useful beyond the MVP's exact comparisons.

## Acceptance criteria

- Each selected capability has documented schema, editor, execution, timeout, and result behaviour.
- Unselected candidates remain out of the supported action/assertion vocabulary.
- The shared schema, editor, runner, and documentation remain aligned.

## Dependencies

- ATR-008 MVP vocabulary
