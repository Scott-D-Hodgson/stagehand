# ATR-038 — Guide least-privilege agent execution

**Epic:** E08  
**Status:** Proposed  
**Priority:** Must  
**Release:** MVP

## User story

As a Stagehand maintainer, I want contributors and AI agents to keep their work scoped to the project directory and avoid unnecessary system or credential access.

## Description

Provide vendor-neutral, least-privilege guidance for people and agents working in the repository. Repository guidance cannot itself restrict an agent's filesystem, process, credential, or network access; describe enforcement only when it is provided by the user's runtime or operating system.

## Acceptance criteria

### AC-1 — Boundary documented

Guidance tells agents to work within the project directory and avoid accessing system files or other directories unless the task requires it and the user authorizes it.

### AC-2 — Least privilege

Guidance recommends avoiding privileged execution and unnecessary host mounts where the runtime exposes those choices.

### AC-3 — Credentials

Host credentials and production secrets are not exposed by default where runtime configuration permits.

### AC-4 — Network policy

Network restrictions are described only when an enforcing runtime or operating-system control is configured.

### AC-5 — Limits stated

Documentation clearly states that repository instructions are not enforcement and describes relevant runtime limitations without claiming isolation the project cannot provide.

## Notes
