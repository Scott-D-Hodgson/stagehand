# ATR-037 — Define AI-agent and BYOA guidance

**Epic:** E08  
**Status:** Proposed  
**Priority:** Must  
**Release:** MVP

## User story

As a Stagehand maintainer, I want shared agent guidance so that different AI coding agents follow the same architecture, conventions, and verification process.

## Description

Provide root AGENTS.md and scoped guidance for modules where needed, without coupling Stagehand to one agent vendor.

## Acceptance criteria

### AC-1 — Root guidance

AGENTS.md describes architecture, coding conventions, tests, security, and change workflow.

### AC-2 — Scoped guidance

Subdirectory guidance is added only where it materially differs from root guidance.

### AC-3 — Vendor neutrality

Guidance is usable by different agents and human contributors.

### AC-4 — Verification

Agents are instructed to run relevant checks and report what they could not run.

### AC-5 — No secret exposure

Guidance prohibits committing secrets or exposing them in logs/reports.
