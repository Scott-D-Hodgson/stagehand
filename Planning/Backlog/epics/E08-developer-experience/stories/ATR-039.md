# ATR-039 — Automate monorepo verification

**Epic:** E08  
**Status:** Proposed  
**Priority:** Must  
**Release:** MVP

## User story

As a maintainer, I want CI to verify affected modules so that changes preserve quality without requiring every component to be deployed together.

## Description

Add shared quality checks with component-aware test/build workflows.

## Acceptance criteria

### AC-1 — Quality checks

CI runs formatting/lint, type checking, and relevant tests.

### AC-2 — Contract validation

Schema and example plans are validated.

### AC-3 — Documentation checks

Markdown and Hugo build checks run.

### AC-4 — Container checks

Development-container configuration/build is validated where practical.

### AC-5 — Scoped workflows

Build/test jobs can be scoped by changed components without skipping required dependent checks.
