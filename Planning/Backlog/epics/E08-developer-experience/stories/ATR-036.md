# ATR-036 — Provide a reproducible development container

**Epic:** E08  
**Status:** In Progress\
**Priority:** Must  
**Release:** MVP

## User story

As a contributor, I want a documented development container so that I can set up a consistent environment without configuring every tool manually.

## Description

Provide a container definition, pinned toolchain, and common verification commands.

## Acceptance criteria

### AC-1 — Container definition

The repository includes a devcontainer configuration and Dockerfile or equivalent build definition.

### AC-2 — Pinned toolchain

Node.js, package manager, and critical tools are versioned or pinned.

### AC-3 — Playwright dependencies

Required browser dependencies and installation steps are documented.

### AC-4 — Common commands

The container supports running tests, linting, type checks, builds, CLI, SPA, and Hugo site.

### AC-5 — Fresh setup

A new contributor can follow the documented process to set up and verify Stagehand.

### AC-6 — CI verification

The container build or its critical setup checks are verified in CI.

## Dependencies

- None identified.
