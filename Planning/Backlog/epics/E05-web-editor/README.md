# E05 — Local-first web editor

> **Living document:** All material in `Planning/` is generated by AI through discussions and direction from the developer; it is not written by hand. It provides structure, guidance, and context for ongoing development, and will be reviewed and updated periodically as Stagehand evolves.

Phase 2 delivers the first user-facing Stagehand capability: a controlled form-based, local-first Vue SPA for non-technical testers to author and validate plans before the CLI runner. It includes variables, shared steps, bounded loops, localized expected values, plan/case configuration, and referenced case files. A raw JSON editor is deferred. The developer will dogfood the editor and refine it through use.

See `stories/` for individual user stories and acceptance criteria.
