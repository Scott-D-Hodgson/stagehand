# ATR-031 — Edit shared steps, variables, loops, and localization

**Epic:** E05  
**Status:** Proposed  
**Priority:** Must  
**Release:** MVP

## User story

As a test author, I want dedicated editing controls for reusable steps and data-driven behaviour so that complex plans can be maintained safely.

## Description

Provide controlled form-based UI affordances for shared groups, data sets, environment-variable references, loops, and localized descriptions before CLI delivery. Do not require users to edit raw JSON.

## Acceptance criteria

### AC-1 — Shared steps

The UI can define and reference shared step groups.

### AC-2 — Data sets

The UI can define named variable sets and select a default.

### AC-3 — Secret references

The UI records environment-variable names without asking to store secret values in the plan.

### AC-4 — Loops

The UI can author a supported bounded loop over a list variable.

### AC-5 — Localization

The UI can edit localized descriptions and expected assertion values by culture while preserving stable IDs. Expected values resolve using the culture selected for the run, following the documented fallback policy.

### AC-6 — Validation

Invalid references or loop definitions are explained clearly.
