# ATR-031 — Edit shared steps, variables, and localization

**Epic:** E05  
**Status:** Proposed  
**Priority:** Must  
**Release:** MVP

## User story

As a test author, I want dedicated editing controls for reusable steps and data-driven behaviour so that complex plans can be maintained safely.

## Description

Provide controlled form-based UI affordances for shared groups, data sets, environment-variable references, and localized descriptions before CLI delivery. Do not require users to edit raw JSON.

## Acceptance criteria

### AC-1 — Shared steps

The UI can define and reference shared step groups.

### AC-2 — Data sets

The UI can define named variable sets and select a default.

### AC-3 — Secret references

The UI records environment-variable names without asking to store secret values in the plan.

### AC-4 — Loops (deferred beyond MVP)

Not an MVP acceptance criterion. Revisit loop authoring with [ATR-018](../../E02-execution-engine/stories/ATR-018.md) if loop execution is scheduled later.

### AC-5 — Localization

The UI can edit localized descriptions and assertion expected values while preserving plan and case IDs. Steps remain identified by case ID and sequence position; results represent the position as a zero-based index and authors do not assign step IDs. Expected values use a required `default` and optional BCP 47 locale overrides; locale keys are canonicalized, equivalent duplicate keys are invalid, and the `default` is used when no locale override matches the run locale. This value fallback is separate from the fallback language for descriptions.

### AC-6 — Validation

Invalid variable, data-set, and shared-step references are explained clearly.
