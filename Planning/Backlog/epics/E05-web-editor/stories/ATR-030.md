# ATR-030 — Export plans and protect unsaved work

**Epic:** E05  
**Status:** Proposed  
**Priority:** Must  
**Release:** MVP

## User story

As a test author, I want to download my edited plan and be warned about unsaved changes so that I do not lose work.

## Description

Support export/download, dirty-state detection, and safe navigation behaviour.

## Acceptance criteria

### AC-1 — Download

The user can download the current plan as JSON.

### AC-2 — Unsaved indicator

The UI indicates when edits have not been exported/saved.

### AC-3 — Navigation warning

The app warns before a supported navigation action that would discard edits.

### AC-4 — Validation feedback

The user can see validation errors before exporting or running a plan.

### AC-5 — Browser compatibility

File access limitations and supported browser behaviours are documented.
