# ATR-035 — Publish documentation using Hugo

**Epic:** E07  
**Status:** Proposed  
**Priority:** Must  
**Release:** MVP

## User story

As a prospective user, I want a discoverable documentation website so that I can learn how to adopt and operate the runner.

## Description

Generate the documentation site from the canonical Markdown source, with Hugo layouts and navigation.

## Acceptance criteria

### AC-1 — Hugo build

The site builds successfully using the documented command.

### AC-2 — Canonical content

User-guide/reference content comes from the repository's Markdown source.

### AC-3 — Navigation

Users can discover getting-started, authoring, reference, integrations, and development sections.

### AC-4 — CI validation

CI checks the Hugo build and relevant links where practical.

### AC-5 — Portability

The source Markdown can be migrated to another wiki manually without dependence on a proprietary content store.

## Verification

- Add unit, integration, or manual verification appropriate to the acceptance criteria.
