# TE-014 — Agent sandbox and guidance

**Status:** Proposed  
**Priority:** Must  
**Related stories:** ATR-037, ATR-038

## Objective

Document vendor-neutral, least-privilege guidance for contributors and AI agents. Explain that repository instructions cannot enforce runtime restrictions, and describe only controls actually provided by a user's agent runtime or operating system.

## Acceptance criteria

- The implementation is documented and version-controlled.
- Relevant unit/integration checks verify the intended behaviour.
- Dependent stories can use the capability through a documented contract.
- Failure modes and security implications are addressed where relevant.

## Notes

Refine this enabler into smaller tasks if implementation reveals independent workstreams.
