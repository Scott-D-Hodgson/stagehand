# TE-017 — Assess and crosswalk ITSP.10.033

**Status:** Later candidate  
**Priority:** Later

## Intent

After the initial ITSG-33-based assessment is useful and reviewed, assess the current ITSP.10.033 security control catalogue and document how its requirements apply to Stagehand and its operating environments.

## Scope to establish when prioritized

- Confirm the authoritative ITSP.10.033 version and applicable profile/tailoring approach.
- Identify controls that changed, were added, removed, or reorganized from the ITSG-33 Annex 3A material currently documented.
- Create a traceable crosswalk, clearly distinguishing product responsibilities from operator/environment responsibilities.
- Review and update control definitions, guidance, implementation recommendations, and assessment status.

## Dependencies

- Initial review of the ITSG-33-based `Planning/Security/` assessment
- Applicable system boundary, deployment model, and organisational security requirements
