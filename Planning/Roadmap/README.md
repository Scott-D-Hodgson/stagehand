# Proposed roadmap

> **Living document:** All material in `Planning/` is generated by AI through discussions and direction from the developer; it is not written by hand. It provides structure, guidance, and context for ongoing development, and will be reviewed and updated periodically as Stagehand evolves.

This is a dependency-informed sequence, not a delivery-date commitment. Each phase has its own folder and detail file; later candidates are tracked separately because they are not assigned to a committed phase.

The planned MVP is the complete Phase 1–4 sequence. It prioritizes a visual Vue editor in Phase 2, before the execution engine and CLI in Phase 3.
