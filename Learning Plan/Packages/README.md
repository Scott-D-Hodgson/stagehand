# Package courses

Each course teaches one Stagehand package through short, single-subject lessons and a final skill check. Use phase lessons for cross-cutting concepts and milestone context; use these courses to understand package responsibilities, source, public APIs, and verification.

## Packages

- [Plan schema course](plan-schema/README.md) - contracts, validation, references, bundles, variables, and data sets.
- [Plan engine course](plan-engine/README.md) - loading, path safety, bundle hand-off, and source fingerprints.
- [Result model course](result-model/README.md) - result contracts, schema/types, runtime validation, accessibility evidence, and policy boundaries.
- [Runner core course](runner-core/README.md) - browser lifecycle, locators, waits, actions, assertions, dispatch, preparation, accessibility, and verification.

Add a package course when that package has implementation worth teaching. Follow the local [`AGENTS.md`](AGENTS.md), keep each lesson to one central question, and label planned behaviour as future work.
