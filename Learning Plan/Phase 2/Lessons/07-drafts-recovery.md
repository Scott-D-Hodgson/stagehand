# Lesson 7: Drafts and recovery

> “What protects an unfinished plan if the tab closes or the editor crashes?” — Drew “Draft Defender” Dawson, Developer

A draft is a local recovery copy, not automatically the authoritative plan file. The editor should clearly identify unsaved changes and let the person choose whether to recover or discard a draft.

Recovery data can contain sensitive test inputs. Store only what is needed, keep it local, and provide a clear way to remove it.
