# Lesson 4: Validation feedback

> “How do we turn a validator's technical complaint into something a person can fix?” — Fiona “Feedback Finder” Flynn, Developer

Validation feedback should say what is wrong, where it is, and what kind of correction is expected. The editor may translate a machine path such as `/cases/1/id` into a form label and focus the related control.

Do not hide the original location: it helps diagnose problems the form cannot display. Feedback must also work with a keyboard and assistive technology.

## Try it

Rewrite “must match pattern” as an actionable message for an invalid case ID. Include the field, the rule, and an example correction.

## You are ready when

You can connect a shared validation error to a visible, accessible, and useful editing action.
