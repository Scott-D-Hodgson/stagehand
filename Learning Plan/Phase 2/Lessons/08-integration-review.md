# Lesson 8: Phase integration review

> “Can someone move from a local file to a valid edited plan without losing work or meaning?” — Uma “UI Unifier” Underwood, Developer

The phase succeeds when the editor joins its parts into one understandable path: import, validate, edit, recover if needed, validate again, and export.

Review boundaries as well as screens. The shared schemas decide whether a document is valid; the editor explains and applies those rules. Local storage supports recovery; it is not a hidden Stagehand account.

## Try it

Walk through one successful edit and one invalid import. Note every point where the person receives feedback or makes a choice.

## You are ready when

You can review the whole authoring journey for data loss, inaccessible feedback, hidden network dependence, and contract drift.
