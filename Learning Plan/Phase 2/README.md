# Phase 2 learning plan

These lessons prepare the developer to deliver [Roadmap Phase 2](../../Planning/Roadmap/Phase-2-visual-authoring/README.md), Stagehand's first user-facing capability. The editor comes before the CLI, so focus on helping a non-technical tester author understandable, valid plans without exposing raw JSON.

1. [Vue application structure and reactive form state](01-vue-application-and-form-state.md)
2. [Plan editing, validation, and accessible interaction](02-plan-authoring-and-validation.md)
3. [Import, export, unsaved work, and offline behaviour](03-local-first-file-workflows.md)

Read the lessons alongside [Epic E05](../../Planning/Backlog/epics/E05-web-editor/README.md) and the shared plan contract. The lessons describe concepts and current decisions; confirm acceptance criteria in the backlog before implementation.
