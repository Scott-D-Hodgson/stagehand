# Phase 2 skill check

1. What is the difference between document state and interface state?
2. Why should the editor use the shared validators instead of making its own rules?
3. What three things should useful validation feedback communicate?
4. Why are recovery drafts not the authoritative plan file?
5. Name two properties of a local-first import and export workflow.

## Answer key

1. Document state belongs in the saved Stagehand file; interface state only helps operate the editor.
2. One shared validator prevents the editor and runner from accepting different documents.
3. What is wrong, where it is, and what kind of correction is expected.
4. They are temporary local safety copies; the person still controls when and where the plan is saved or exported.
5. Examples include no required account, no central plan service, explicit file permission, local validation, and a download fallback.
