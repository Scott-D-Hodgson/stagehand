# Learning Plan acronyms and abbreviations

This glossary covers acronyms used in the Learning Plan. Backlog identifiers are explained as groups rather than listed individually.

| Acronym | Meaning |
|---|---|
| ADR | Architecture Decision Record. |
| AI | Artificial intelligence. |
| API | Application programming interface. |
| BCP 47 | Best Current Practice 47, the IETF language-tag format. |
| ATR-### | Stagehand backlog story identifier. The project materials do not define an expansion for the `ATR` prefix. |
| CI | Continuous integration. |
| CI/CD | Continuous integration and continuous delivery or deployment. |
| CLI | Command-line interface. |
| CSS | Cascading Style Sheets. |
| DOM | Document Object Model. |
| E01–E09 | Backlog epic identifiers. |
| HTML | HyperText Markup Language. |
| IANA | Internet Assigned Numbers Authority. |
| ID | Identifier. |
| ISC | Internet Systems Consortium; the ISC licence applies to some bundled axe components. |
| JSON | JavaScript Object Notation. |
| LICENSE | The conventional filename for a repository's licence text; not an acronym in this context. |
| LTS | Long-term support. |
| M0–M7 | Work-plan milestone identifiers; M0 is repository bootstrap and M1–M7 cover Phase 1. |
| MDN | Mozilla Developer Network. |
| MIT | Massachusetts Institute of Technology; the project uses the MIT Licence. |
| MPL-2.0 | Mozilla Public License, version 2.0. |
| MVP | Minimum viable product. |
| OS | Operating system. |
| PR | Pull request. |
| RFC | Request for Comments; a series of Internet standards and guidance documents. |
| SHA-256 | Secure Hash Algorithm 256; produces a 256-bit digest. |
| SPA | Single-page application. |
| TE-### | Technical-enabler identifier. |
| UI | User interface. |
| URI | Uniform Resource Identifier. |
| URL | Uniform Resource Locator. |
| XPath | XML Path Language. |
| UTC | Coordinated Universal Time. |
| US | United States. |
| XML | Extensible Markup Language. |
| YAML | A human-readable data-serialization language; commonly expanded as “YAML Ain't Markup Language.” |

Vue, Playwright, axe, and Hugo are product or project names, not acronyms in these materials.
