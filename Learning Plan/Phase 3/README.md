# Course: Phase 3 — Execution engine and CLI

Phase 3 turns validated documents into controlled automated runs and exposes that behaviour through a command-line interface (CLI).

## In this phase you will learn

- How complete plans are orchestrated across isolated cases.
- How concurrency, timeouts, cancellation, failure, and cleanup interact.
- How CLI commands, overrides, exit behaviour, and automation fit around the engine.

## Do I need this phase?

- [ ] I am building full-plan execution or the CLI.
- [ ] I need to reason about concurrent cases or cancellation.
- [ ] I am defining automation-friendly errors and exit codes.

## Prerequisites

Complete the Phase 1 contracts, browser lifecycle, inputs, and error-policy lessons first.
