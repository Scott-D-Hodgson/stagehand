# Lesson 1: Full-plan orchestration

> “How does one validated plan become a complete, orderly test run?” — Orson “Orchestration Operator” Owens, Developer

**Orchestration** means coordinating the whole run: resolve inputs, start the required browser resources, execute cases, collect outcomes, and finish cleanly. It is the conductor of the orchestra, not the musician playing every action.

Full-plan orchestration is planned Phase 3 work. It should build on the existing loaders, validators, and case-step runner rather than duplicate them.
