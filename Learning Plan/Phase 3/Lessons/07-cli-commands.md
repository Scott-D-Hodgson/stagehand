# Lesson 7: CLI command structure

> “What should a command-line user type, and what should each command promise?” — Clara “CLI Crafter” Clark, Developer

A command-line interface (CLI) gives named commands, options, help text, output, and exit codes to people and automation. Commands should be small promises, such as validate a plan or run it.

The CLI is a thin doorway into shared packages. It should not create different validation or execution rules.

## Try it

Draft help text for a validation command and a run command. Separate required arguments from optional settings.

## You are ready when

You can design predictable commands that reuse package behaviour and explain errors plainly.
