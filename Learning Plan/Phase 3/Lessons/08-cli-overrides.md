# Lesson 8: CLI overrides

> “When a setting appears in several places, which value wins?” — Owen “Override Organizer” Ortiz, Developer

An override changes a chosen setting for one run without rewriting the plan. Precedence is the documented order used when defaults, plan values, case choices, and command options overlap.

MVP data-set selection is per case. Protected environment values must stay protected after resolution and must not appear in output or retained evidence.
