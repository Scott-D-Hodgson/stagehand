# Lesson 6: Security and responsible execution

> “Who decides what Stagehand may test, and what damage could a test cause?” — Seth “Security Sentinel” Scott, Developer

Stagehand executes browser actions against real targets. The operator must have authorization and understand side effects such as creating accounts, sending messages, or changing data.

The repository's security materials are assessment aids, not proof of compliance. Safe defaults, local-first handling, dependency licences, redaction, and honest limitations all support responsible use.

## Try it

Create a pre-run checklist covering authorization, target environment, test data, side effects, and artifact handling.

## You are ready when

You can review a proposed run for authority, scope, data risk, and recoverability.
