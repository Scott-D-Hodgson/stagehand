# Lesson 2: Accessibility interpretation

> “What does an axe finding tell us—and what does it not prove?” — April “Accessibility Analyst” Avery, Developer

An axe scan can report violations, incomplete checks needing human review, affected nodes, impact, tags, and supporting details. A clean automated scan does not prove complete accessibility.

Stagehand retains selected evidence such as HTML, target, failure summary, impact, XPath when available, related nodes, and tags. Requested tags narrow the scan; no requested tags means axe's default scope.

## Try it

Explain a result containing no violations but two incomplete checks to a non-specialist.

## You are ready when

You can interpret automated findings without turning them into a false compliance claim.
