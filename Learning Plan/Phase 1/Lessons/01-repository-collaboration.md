# Lesson 1: Repository collaboration

> “How do we change Stagehand safely when one person may be both author and reviewer?” — Rory “Review Ready” Ross, Developer

Stagehand uses pull requests (PRs) as a deliberate review pause. During solo development, GitHub cannot treat the author's approval as independent review, so the owner uses a manual self-review checklist and no required native approvals. When independent reviewers join, contributor changes should receive independent approval.

Owner PRs normally use merge commits to preserve their commits; contributor PRs normally use squash merges. This is a human convention, not an automatically enforced rule.
