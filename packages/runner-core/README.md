# `@stagehand/runner-core`

This package starts one Playwright-managed Chromium process for a run and creates an isolated browser context and page for each case. Run-wide locale and headless settings use Stagehand defaults when omitted. Each case inherits the run's viewport and time zone, and may override either setting. Headless mode is run-wide because it is selected at browser launch.

The public entry point exports `startBrowserRun`. It returns a run with `createCaseSession` and `close` methods. Each case session exposes `navigate`, which accepts an absolute HTTP/HTTPS URL and uses `domcontentloaded` with a 30-second timeout by default; the supported `waitUntil` and timeout settings can be overridden. It also exposes `resolveLocator`, which accepts one schema locator (`role`, `label`, `css`, or `xpath`) and returns its unique Playwright locator. Role and label names are matched exactly. A missing match is retried up to three times, with one-second gaps, within the supplied timeout; the default is 30 seconds. The timeout is divided across the locator waits after reserving retry gaps. Multiple matches fail immediately. The `click` method uses the same locator rules and a 30-second default timeout; locator lookup and Playwright click actionability share that timeout budget. Scrolling is enabled by default, and `scrollIntoView: false` makes Playwright fail if the target is outside the viewport. Case sessions also expose `runWaitList`, which runs wait items sequentially: locator waits poll once per second for exactly one match, page-state waits support `domcontentloaded` and `networkidle`, and fixed delays may last 1 to 30,000 milliseconds. Each item defaults to a 30-second timeout; a shorter timeout bounds the wait and causes a `WaitExecutionError` if it expires. `executeSteps(caseId, steps)` initially dispatches validated `navigate` and `click` steps in sequence; click steps run their `before` and `after` waits. It throws a `StepExecutionError` with the case ID, zero-based step index, action, and original cause when a step fails. Other actions, assertions, plan loading, result records, and case/run outcome aggregation are not implemented by this first dispatcher. Close each case session when its case finishes, and call the run's `close` method in a `finally` block. Closing the run waits for in-flight case setup, rejects sessions that have not finished setup when shutdown starts, closes any active case sessions, and then closes Chromium. Concurrent run `close` calls await the same cleanup.

Build and test from the repository root:

```sh
npm test --workspace @stagehand/runner-core
```

The tests import the public package name and replace the Playwright launch method with small test doubles, so they do not require a downloaded browser.
